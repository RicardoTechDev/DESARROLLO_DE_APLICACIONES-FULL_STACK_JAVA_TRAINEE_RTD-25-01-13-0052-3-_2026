# Portafolio Profesional - Desarrollador Full Stack

Este repositorio contiene mi portafolio web personal, diseñado para destacar mi experiencia, habilidades técnicas y proyectos destacados como Desarrollador Full Stack e Instructor.

## Tecnologías Utilizadas
* HTML5 (Semántico)
* CSS3 (Variables Custom, Flexbox, Grid)
* JavaScript (Vanilla, ES6+)
* Bootstrap 5 (Sistema de grillas y componentes base)

## Estructura del Proyecto
El código sigue una separación estricta de responsabilidades:
* `index.html`: Estructura principal.
* `assets/css/style.css`: Estilos visuales personalizados.
* `assets/js/script.js`: Interactividad y efectos del DOM.

## Instrucciones de Ejecución
1. Clona este repositorio o descarga los archivos.
2. Abre la carpeta raíz en Visual Studio Code.
3. Instala y ejecuta la extensión **Live Server**.
4. El proyecto se abrirá en tu navegador por defecto (`localhost:5500`).
