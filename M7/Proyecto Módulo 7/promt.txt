### Organización del proyecto

Entrega el proyecto utilizando obligatoriamente la siguiente estructura:

```text
portfolio/
│
├── index.html
│
├── README.md
│
├── assets/
│   │
│   ├── css/
│   │   └── style.css
│   │
│   ├── js/
│   │   └── script.js
│   │
│   └── img/
│       │
│       ├── perfil/
│       │   └── perfil.jpg
│       │
│       ├── proyectos/
│       │   ├── proyecto-1.jpg
│       │   ├── proyecto-2.jpg
│       │   └── proyecto-3.jpg
│       │
│       └── icons/
│
└── favicon.ico
```

Todos los recursos del sitio deben estar organizados dentro de la carpeta `assets`.

Por ejemplo:

```html
<link rel="stylesheet" href="assets/css/style.css">

<script src="assets/js/script.js"></script>

<img src="assets/img/perfil/perfil.jpg" alt="Fotografía profesional">
```

No coloques todo el CSS y JavaScript dentro del archivo HTML.

Mantén correctamente separados:

* HTML
* CSS
* JavaScript
* Imágenes y recursos visuales

### Responsive Design

Presta especial atención al comportamiento responsivo.

Verifica específicamente:

* Navbar en móvil
* Hero en pantallas pequeñas
* Tamaño de la fotografía
* Botones en móvil
* Cards de proyectos
* Timeline de experiencia
* Tecnologías
* Formulario de contacto
* Footer

En teléfonos móviles:

* Evita textos demasiado grandes.
* Los botones deben reorganizarse cuando sea necesario.
* Las cards deben ocupar correctamente el ancho disponible.
* No debe existir scroll horizontal.
* Las imágenes nunca deben salirse de sus contenedores.
* El menú debe convertirse correctamente en menú hamburguesa.

Utiliza media queries adicionales cuando Bootstrap no sea suficiente.
